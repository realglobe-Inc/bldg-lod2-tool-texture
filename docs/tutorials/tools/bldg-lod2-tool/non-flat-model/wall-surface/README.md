# 壁面を作る
- 屋根ポリゴンの回転方向を見て、歯車的に壁面の回転方向を決める
- 壁のエッジを共有する屋根ポリオンのうち、高い方の屋根ポリゴンだけ壁を作るようにする
  - ![wall-surface-01.png](./wall-surface-01.png)
- 歯車的に、屋根面の回転は反時計回りなら、壁面の回転は時計回りになる。\nここで、壁面の回転を反時計回りに変更
  - ![wall-surface-02.png](./wall-surface-02.png)
