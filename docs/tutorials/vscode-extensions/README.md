# 便利な VSCode Extensions

| Extension 名 | 詳細 |
|-|-|
| Python | Python言語 IntelliSense とコード自動完成 |
| autopep8 | コード自動整形 |
| Flake8 | コーディング規約指摘 |
| GitLens | VSCode上で以前のコミット記録と比較しながらデバッグ |
| Pylance | コーディング規約指摘 |
| Markdown All in One | 書いたをマークダウンのプレビュー |
| Mermaid Graphical Editor | シーケンス図などを作成 |
| mesh-viewer | 3D モデルビュアー（テクスチャーなし） |
